# Six adapted baselines: Xining land-use ranking

These six notebooks reproduce the **13-object baseline rankings** used in Table 4 of the manuscript. Each notebook is self-contained: its small, fixed input matrices are embedded in the first code cell. No local files or model retraining are required.

## Run

1. Install Python 3 and the dependencies: `pip install numpy jupyterlab nbformat`.
2. Run `jupyter lab`, open any notebook, and run all cells from top to bottom.
3. The last cell prints the ranking and each object's score. Ties are retained.
4. To check all six rankings and the consensus score calculation, run `python verify_CAS.py` in this folder.

## Shared input and settings

- Objects: `O1`–`O13`; four experts; six attributes. Attribute 6 is cost-type.
- The embedded `X_GNN` is the fixed aggregated GNN output from the Xining study. `X1`–`X4` are the original expert matrices; some adaptations use expert disagreement or graph structure.
- Conversion: deterministic `FuzzyNorm`, `q=5`, `eps=0.05`, with the same minimal repair for infeasible three-decimal interior pairs.
- Expert weights: `(0.2506, 0.2519, 0.2607, 0.2368)`.
- Shared external attribute weights: `(0.247, 0.088, 0.259, 0.166, 0.192, 0.048)`.
- Embedded-input SHA-256 (canonical JSON): `915a03f9bef24a3f651d3398d3a590e28027949269ab027c0c1096aef4db92a5`. Each notebook prints this value.

| Notebook | Selected settings | Input adaptation |
| --- | --- | --- |
| `n-IPFSGraph.ipynb` | `n=3`, `p=1`, seven linguistic levels | Converts GNN membership to linguistic values. |
| `GNFAM.ipynb` | `(alpha,beta,gamma)=(0.1,0.6,0.3)`, `I=2 sigma` | Ranks pre-assignment suitability; no task assignment. |
| `CIRF-TOPSIS.ipynb` | PC level `0.001`, 100 bootstraps, retain count `70`, direct share `0.1`, seed `2026` | Label-free graph/rough-set adaptation with TOPSIS. |
| `FKGS.ipynb` | sampling `0.2`, threshold `0.4`, head sharpness `5`, seed `2026` | Uses dataset-derived ordinal groups and fuzzy rule matching. |
| `IVPFGraph.ipynb` | range intervals, neutral `1`, radius `0.5` capped at `0.25`, edge scale `0.5` | Builds interval-valued picture fuzzy inputs from GNN values and expert spread. |
| `ZagrebGraph.ipynb` | expert-edge share `0.5` | Blends expert and GNN q-ROF edge values; this blend is an added input adapter. |

## Result interpretation

The proposed ranking is **fixed externally** and is not regenerated by these notebooks. `verify_CAS.py` forms the exact Kemeny reference from that fixed ranking and the six baseline rankings. It excludes the three internal pairs of the `O6=O9=O10` tie, leaving 75 comparable pairs. The table values and full scores are in `rankings_and_CAS.json`.
